El login es el proceso que permite identificar a un usuario antes de darle acceso a una aplicación. Gracias a la autenticación, solo las personas autorizadas pueden utilizar determinadas funciones o consultar cierta información. Algunas rutas deben estar protegidas porque contienen datos privados o permiten realizar cambios importantes en el sistema. Esto ayuda a mantener la seguridad de la plataforma. No se deben exponer públicamente contraseñas, documentos de identidad, números de teléfono, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.

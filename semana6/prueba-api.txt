La ruta POST /registro recibe datos enviados en formato JSON.

Al enviar:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

el servidor responde con:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Esto confirma que los datos fueron recibidos correctamente mediante req.body.

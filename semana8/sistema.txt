El comando uname -a muestra información del sistema operativo, como el nombre del sistema, la versión del kernel y detalles del equipo.

El comando whoami muestra el nombre del usuario que está utilizando el sistema en ese momento.

Conocer esta información es útil para administrar servidores porque permite identificar el sistema operativo, verificar el usuario activo y realizar tareas de mantenimiento y seguridad de forma adecuada.
